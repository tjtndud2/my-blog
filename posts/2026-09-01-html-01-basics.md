## 1. HTML이란?

**HTML(HyperText Markup Language)** 은 웹 페이지의 **구조와 의미**를 정의하는 마크업 언어다. 프로그래밍 언어처럼 계산이나 조건 분기를 하지 않고, 내용에 "이건 제목", "이건 목록"이라고 표시(markup)만 한다.

| 단어 | 의미 |
|---|---|
| HyperText | 다른 문서로 연결(링크)되는 텍스트 |
| Markup | 태그로 내용의 역할을 표시하는 것 |
| Language | 정해진 문법이 있는 언어 |

웹 프론트엔드는 세 기술이 역할을 나눈다.

| 기술 | 역할 | 비유 |
|---|---|---|
| HTML | 구조 · 내용 | 건물의 뼈대 |
| CSS | 디자인 · 레이아웃 | 인테리어 |
| JavaScript | 동작 · 상호작용 | 전기 · 배관 |

### 브라우저가 HTML을 보여주는 과정

1. 브라우저가 `.html` 파일을 위에서 아래로 읽는다.
2. 태그를 해석해 **DOM(Document Object Model)** 이라는 트리 구조를 만든다.
3. CSS를 적용해 화면에 그린다(렌더링).

그래서 HTML은 **작성 순서대로 화면에 배치**된다. 문법이 조금 틀려도 브라우저가 알아서 보정해 보여주기 때문에, 눈으로는 멀쩡해 보여도 구조가 틀린 경우가 많다.

## 2. 태그, 요소, 속성

```html
<a href="https://github.com">깃허브</a>
```

| 구성 | 예시 | 설명 |
|---|---|---|
| 여는 태그 | `<a>` | 요소의 시작 |
| 닫는 태그 | `</a>` | 요소의 끝 (`/` 붙음) |
| 속성(attribute) | `href="..."` | 태그에 추가 정보 제공, `이름="값"` 형식 |
| 내용(content) | `깃허브` | 태그 사이의 실제 내용 |
| 요소(element) | 전체 | 여는 태그 + 내용 + 닫는 태그 |

- **빈 요소(void element)**: 내용이 없어 닫는 태그가 없는 태그 — `<br>`, `<hr>`, `<img>`, `<input>`, `<meta>`
- **중첩(nesting)**: 태그 안에 태그를 넣을 수 있다. 바깥이 **부모**, 안쪽이 **자식**. 먼저 연 태그를 나중에 닫아야 한다.

```html
<p><strong>중요</strong>한 내용</p>   <!-- ✅ -->
<p><strong>중요</p></strong>         <!-- ❌ 닫는 순서가 꼬임 -->
```

### 전역 속성 (어떤 태그에나 쓸 수 있는 속성)

| 속성 | 용도 |
|---|---|
| `id` | 요소의 고유한 이름 (페이지 안에서 중복 불가) |
| `class` | 요소의 그룹 이름 (여러 요소가 공유 가능, CSS에서 주로 사용) |
| `style` | 인라인 CSS 작성 |
| `title` | 마우스를 올렸을 때 나오는 툴팁 |

> 속성 값은 따옴표 없이도 동작하는 경우가 있지만(`href=hobby.html`), 값에 공백이 들어가면 깨진다. **항상 큰따옴표로 감싸는 습관**을 들이자.

### 주석

```html
<!-- 화면에 표시되지 않는 메모 -->
```

주석은 화면에는 안 보이지만 **페이지 소스 보기로 누구나 볼 수 있다.** 비밀번호나 내부 정보를 적으면 안 된다.

## 3. HTML 문서의 기본 구조

VS Code에서 `!` + `Tab`을 누르면 자동 생성된다.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <!-- 화면에 보이는 내용은 여기에 -->
</body>
</html>
```

| 코드 | 의미 |
|---|---|
| `<!DOCTYPE html>` | HTML5 문서임을 브라우저에 알림 (태그가 아니라 선언) |
| `<html lang="en">` | 최상위 요소. `lang`은 문서의 주 언어 |
| `<head>` | 화면에 안 보이는 **문서 정보(메타데이터)** 영역 |
| `<meta charset="UTF-8">` | 문자 인코딩 지정 → 한글 깨짐 방지 |
| `<meta name="viewport" ...>` | 모바일 화면 너비에 맞게 표시 (반응형의 출발점) |
| `<title>` | 브라우저 탭 제목, 검색 결과·북마크에 노출 |
| `<body>` | 실제로 **화면에 보이는 내용** 영역 |

### ➕ head에 자주 들어가는 것들

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="HTML 기초 개념 정리">  <!-- 검색 결과 요약문 -->
    <title>HTML 기초 정리</title>
    <link rel="stylesheet" href="style.css">                   <!-- 외부 CSS 연결 -->
    <link rel="icon" href="favicon.ico">                       <!-- 탭 아이콘 -->
    <script src="main.js" defer></script>                      <!-- 외부 JS 연결 -->
</head>
```

> 💡 한국어 페이지라면 `lang="ko"`로 바꾸자. 스크린 리더 발음, 검색 엔진, 브라우저 번역 기능이 이 값을 참고한다. `<title>Document</title>`도 기본값 그대로 두지 말 것.

## 4. 글자 관련 태그

### 4-1. 제목 `<h1>` ~ `<h6>`

숫자가 작을수록 크고 중요한 제목이다.

```html
<h1>큰 제목</h1>
<h2>두 번째 큰 제목</h2>
<!-- ... -->
<h6>여섯 번째 큰 제목</h6>
```

> 💡 제목 태그는 **글자 크기용이 아니라 문서의 목차 구조**다.
> - `<h1>`은 보통 페이지당 하나 (페이지의 대주제)
> - `<h2>` 다음에 `<h4>`로 건너뛰지 말고 순서대로
> - 크기를 키우고 싶어서 `<h1>`을 쓰는 건 잘못된 사용 → 크기는 CSS로

### 4-2. 줄바꿈 `<br>`, 수평선 `<hr>`

```html
<br>  <!-- 줄을 바꿈 -->
<hr>  <!-- 가로 구분선 -->
```

> `<br>`을 여러 번 써서 간격을 벌리는 건 피하자. 간격은 CSS의 `margin`, `padding`으로 조절한다.

### 4-3. 문단 `<p>` vs `<pre>`

HTML은 기본적으로 **연속된 공백과 줄바꿈을 공백 한 칸으로 합쳐서** 표시한다. (공백 병합)

```html
<p>p태그는 문단 영역을 나누는 태그이지만,
    한 칸의 공백만 입력해주고, 줄바꿈은
    적용하지 않게 된다.
</p>

<pre>
    pre태그는 여러 칸 띄어쓰기              혹은
    줄 바꿈 등을 포함해서 화면에 표현한다.
</pre>
```

| 태그 | 공백·줄바꿈 | 글꼴 | 주 용도 |
|---|---|---|---|
| `<p>` | 한 칸으로 합침 | 기본 글꼴 | 일반 문단 |
| `<pre>` | 작성한 그대로 유지 | 고정폭 글꼴 | 코드, 아스키 아트 |

> ➕ 코드를 보여줄 땐 `<pre><code>...</code></pre>` 조합이 정석이다. 문장 속 짧은 코드는 `<code>`만 쓴다.

### 4-4. 텍스트 꾸밈 태그

```html
<strong>굵게</strong>  <b>굵게</b>
<em>기울임</em>        <i>기울임</i>
<mark>형광펜</mark>
<u>밑줄</u>
<small>작게</small>
H<sub>2</sub>O, m<sup>2</sup>
<s>취소선</s>
```

| 태그 | 화면 효과 | 의미 |
|---|---|---|
| `<strong>` | 굵게 | **중요한** 내용 |
| `<b>` | 굵게 | 의미 없이 시각적으로만 굵게 |
| `<em>` | 기울임 | **강조** (읽을 때 억양이 바뀌는 부분) |
| `<i>` | 기울임 | 의미 없이 기울임 (용어, 외국어 등) |
| `<mark>` | 형광펜 | 하이라이트 |
| `<u>` | 밑줄 | 텍스트에 주석 표시 |
| `<small>` | 작게 | 부가 설명, 저작권 문구 |
| `<sub>` / `<sup>` | 아래 / 위 첨자 | H₂O, m² |
| `<s>` | 취소선 | 더 이상 유효하지 않은 내용 (할인 전 가격 등) |

> 💡 **생김새는 같아도 의미가 다르다**
> `<strong>`과 `<b>`, `<em>`과 `<i>`는 화면에서 똑같지만 **의미(semantic)** 가 다르다. 스크린 리더와 검색 엔진은 `<strong>`, `<em>`을 중요한 내용으로 인식한다.
> "중요해서 굵게" → `<strong>` / "보기 좋으라고 굵게" → CSS `font-weight`
> `<u>`는 링크와 헷갈려서 실무에선 잘 쓰지 않는다.

### 실습: 상품 상세 문구

```html
<h2>겨울 패딩 점퍼</h2>
<p>정가 <s>129,000원</s> → 89,000원</p>
<p><mark>이번주까지만</mark> 이 가격입니다.</p>

<h3>소재</h3>
<p>겉감 폴리 100%, 충전재 거위털 80%</p>
<p>보관 시 1m<sup>2</sup> 이상 공간을 두세요</p>
```

할인 전 가격처럼 "더 이상 유효하지 않은 정보"에 `<s>`가 딱 맞는다.

### 4-5. 인용 태그

| 태그 | 종류 | 설명 |
|---|---|---|
| `<blockquote>` | 블록 | 다른 곳에서 가져온 긴 인용문 (들여쓰기되어 표시) |
| `<q>` | 인라인 | 문장 속 짧은 인용 (자동으로 따옴표가 붙음) |

```html
<blockquote>설명이 짧아서 좋았습니다.</blockquote>
<p>그는 <q>HTML은 구조다</q>라고 말했다.</p>
```

## 5. ➕ 특수 문자 (HTML 엔티티)

`<`, `>`는 태그로 해석되기 때문에 화면에 그대로 보여주려면 엔티티를 써야 한다.

| 표시 | 엔티티 | 설명 |
|---|---|---|
| `<` | `&lt;` | less than |
| `>` | `&gt;` | greater than |
| `&` | `&amp;` | ampersand |
| `"` | `&quot;` | 큰따옴표 |
| (공백) | `&nbsp;` | 줄바꿈되지 않는 공백 (공백 병합 무시) |
| `©` | `&copy;` | 저작권 표시 |

```html
<p>&lt;p&gt; 태그는 문단을 만든다.</p>   <!-- 화면: <p> 태그는 문단을 만든다. -->
```

## ✅ 마무리 요약

- HTML은 **구조와 의미**를 담당, 꾸미기는 CSS 몫
- 태그 + 속성 + 내용 = 요소, 빈 요소는 닫는 태그가 없다
- `<head>`는 문서 정보, `<body>`는 화면 내용
- 제목 태그는 크기가 아니라 **목차 구조**
- `<p>`는 공백을 합치고 `<pre>`는 그대로 유지
- 같은 모양이라도 `<strong>`/`<em>`은 의미가 있고 `<b>`/`<i>`는 없다
