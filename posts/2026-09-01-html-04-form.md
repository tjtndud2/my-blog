## 1. `<form>` — 사용자 입력을 서버로 보내는 양식 ⭐

로그인, 회원가입, 검색창 등 **사용자가 값을 입력하는 모든 곳**에 폼이 쓰인다. `<form>` 안의 `<input>` 등으로 받은 데이터를 서버로 전달한다.

```html
<form action="search" method="post">
    <label>검색 할 내용 : </label>
    <input type="text" name="search" required>
    <button type="submit">검색!</button>
</form>
```

| 속성 | 설명 |
|---|---|
| `action` | 입력값을 **전송받을 서버 주소** (`#`이면 현재 페이지) |
| `method` | 전송 방식: `get` 또는 `post` (생략 시 `get`) |

### 실행 흐름

1. 사용자가 값을 입력하고 전송 버튼을 누른다.
2. 브라우저가 `required` 같은 기본 유효성 검사를 한다. 통과 못 하면 말풍선 경고가 뜨고 전송이 멈춘다.
3. 통과하면 `name=값` 쌍들을 모아 `action` 주소로 `method` 방식에 맞춰 보낸다.
4. 페이지가 서버의 응답 페이지로 바뀐다.

## 2. GET vs POST

| 구분 | GET | POST |
|---|---|---|
| 데이터 위치 | **URL 뒤**에 붙음 | 요청 **본문(body)** 에 담김 |
| 주소창 노출 | 보임 | 안 보임 |
| 길이 제한 | 있음 (URL 길이 제한) | 사실상 없음 |
| 북마크 / 공유 | 가능 | 불가능 |
| 주 용도 | 검색, 조회, 필터링 | 로그인, 회원가입, 글 작성, 파일 업로드 |

```
GET 전송 시 주소창: https://example.com/search?search=html&page=1
                                              └ ? 뒤로 name=value 쌍이 & 로 연결
```

> ⚠️ POST는 주소창에 안 보일 뿐 **암호화되는 게 아니다.** 개발자 도구(Network 탭)로 누구나 볼 수 있다. 실제 보안은 **HTTPS**가 담당한다.

## 3. `<input>`과 `name`, `value`

서버는 **`name`을 키(key), 입력값을 값(value)** 으로 데이터를 받는다.

> ⭐ **`name`이 없는 입력 요소는 서버로 전송되지 않는다.**

| 속성 | 역할 |
|---|---|
| `type` | 입력 종류 (생략 시 `text`) |
| `name` | 서버로 보낼 때의 키 |
| `value` | 기본값 / 전송될 값 |
| `id` | `<label>` 연결, CSS·JS용 고유 이름 |
| `placeholder` | 입력 전 흐릿하게 보이는 안내 문구 |
| `size` | 입력창의 보이는 너비 (글자 수 기준) |

```html
<label for="userId">아이디 : </label>
<input type="text" id="userId" name="userId" size="60" placeholder="아이디를 입력해주세요">

<label>비밀번호 : </label>
<input type="password" name="userPwd" size="40" placeholder="비밀번호를 입력해주세요">
```

## 4. 다양한 `input type`

### 4-1. 텍스트 계열

| type | 실행 모습 |
|---|---|
| `text` | 한 줄 텍스트 입력창 |
| `password` | 입력값이 `●●●`로 가려짐 |
| `search` | 검색용 입력창 (브라우저에 따라 지우기 ✕ 버튼 표시) |
| `email` | 전송 시 `@` 포함 형식인지 자동 검사, 모바일에선 `@` 있는 키보드 |
| ➕ `tel` | 전화번호 (모바일에서 숫자 키패드) |
| ➕ `url` | 주소 형식 자동 검사 |

### 4-2. 숫자 계열

```html
<input type="number" name="amount" min="0" max="10" value="0" step="3">
<input type="range"  name="point"  min="0" max="100" value="10">
```

| type | 실행 모습 |
|---|---|
| `number` | 숫자 입력창 + 위/아래 증감 버튼 |
| `range` | 좌우로 끄는 슬라이더 (정확한 값은 안 보임) |

| 속성 | 의미 |
|---|---|
| `min` / `max` | 최솟값 / 최댓값 |
| `step` | 증감 단위 (`step="3"`이면 0 → 3 → 6 → 9) |
| `value` | 초깃값 |

### 4-3. 날짜 / 시간 계열

```html
<input type="date" name="date">
<input type="month" name="month">
<input type="week" name="week">
<input type="time" name="time">
<input type="datetime-local" name="datetime-local">
```

| type | 실행 모습 / 전송 값 형식 |
|---|---|
| `date` | 달력 선택기 → `2026-10-18` |
| `month` | 연·월 선택기 → `2026-10` |
| `week` | 주 선택기 → `2026-W42` |
| `time` | 시간 선택기 → `14:30` |
| `datetime-local` | 날짜 + 시간 → `2026-10-18T14:30` |

> ⚠️ `type="datetime"`은 **폐기된(obsolete) 타입**이다. 브라우저가 일반 텍스트 입력창으로 처리하므로 `datetime-local`을 쓴다.
> 날짜 선택기 모양은 브라우저마다 다르다.

### 4-4. 선택 계열 — 라디오 vs 체크박스

```html
<!-- 라디오: name이 같은 것끼리 한 그룹 → 하나만 선택 -->
<label>성별 : </label>
<input id="male" type="radio" name="gender" value="남성">
<label for="male">남성</label>
<input id="female" type="radio" name="gender" value="여성">
<label for="female">여성</label>

<!-- 체크박스: 여러 개 선택 가능 -->
<label>취미 : </label>
<input type="checkbox" id="baseball" name="hobby" value="야구" checked>
<label for="baseball">야구</label>
<input type="checkbox" id="basketball" name="hobby" value="농구">
<label for="basketball">농구</label>
<input type="checkbox" id="football" name="hobby" value="축구">
<label for="football">축구</label>
```

| type | 선택 개수 | 핵심 |
|---|---|---|
| `radio` | **하나만** | ⭐ **`name` 값을 같게 맞춰야 하나의 그룹** (다르면 전부 선택돼 버림) |
| `checkbox` | 여러 개 | `checked`로 기본 선택 |

- 화면에 보이는 "남성"은 `<label>`의 글자이고, 서버로 가는 건 `value` 값이다 → `gender=남성`
- `value`를 생략하면 체크 시 `on`이 전송된다.
- 체크박스를 여러 개 고르면 같은 `name`으로 여러 번 전송된다 → `hobby=야구&hobby=축구`
- 체크 안 한 항목은 아예 전송되지 않는다.

### 4-5. 기타 type

| type | 실행 모습 |
|---|---|
| `color` | 색상 선택기 → `#ff0000` 형식으로 전송 |
| `file` | "파일 선택" 버튼, `multiple`이면 여러 개 선택 |
| `hidden` | 화면에 안 보이지만 값은 서버로 전송 (게시글 번호 등) |
| `submit` | 폼 전송 버튼 (`value`가 버튼 글자) |
| `reset` | 입력값을 처음 상태로 되돌리는 버튼 |
| ➕ `button` | 아무 동작 없는 버튼 (JS용) |

> ➕ 파일 업로드 폼은 `<form method="post" enctype="multipart/form-data">`로 설정해야 파일 내용이 실제로 전송된다.
> `hidden`도 **개발자 도구로 보고 수정할 수 있다.** 비밀 값을 담으면 안 된다.

## 5. `<label>` — 입력창의 이름표

`<label>`의 `for` 값과 `<input>`의 `id` 값을 맞추면 둘이 연결된다.

```html
<input id="male" type="radio" name="gender" value="남성">
<label for="male">남성</label>
```

연결되면 **"남성" 글자를 클릭해도 라디오 버튼이 선택**된다. 작은 버튼을 정확히 누르지 않아도 돼서 편하고, 스크린 리더도 입력창의 이름을 읽어준다.

`for`/`id` 대신 `<label>`로 감싸는 방법도 있다.

```html
<label><input type="checkbox" name="hobby" value="야구"> 야구</label>
```

> 💡 `placeholder`는 입력하면 사라지므로 **`<label>`을 대신할 수 없다.** 항상 label을 함께 쓰자.

## 6. `<select>`와 `<option>` — 드롭다운

```html
<label>국적 : </label>
<select name="nation">
    <option value="ko">한국</option>
    <option value="ch">중국</option>
    <option value="jp" selected>일본</option>
    <option value="etc">그 외</option>
</select>
```

- 클릭하면 목록이 펼쳐지고 하나를 고르는 드롭다운이 된다.
- 화면에 보이는 `한국`, `중국`은 **사용자를 위한 데이터**
- 서버로 전송되는 건 **`name`과 `value`** → `nation=jp` (개발자를 위한 데이터)

| 속성 | 대상 | 설명 |
|---|---|---|
| `selected` | option | 기본 선택 항목 |
| `size` | select | 한 번에 보여줄 항목 수 → 드롭다운 대신 스크롤 목록 상자로 바뀜 |
| `multiple` | select | 여러 항목 선택 가능 (Ctrl / Shift + 클릭) |

```html
<select name="nation2" size="2" multiple>
    <option value="ko">한국</option>
    <option value="ch">중국</option>
</select>
```

> ➕ `<optgroup label="아시아">`로 옵션을 그룹 지을 수 있다.
> ➕ 직접 입력도 하고 추천 목록에서 고를 수도 있게 하려면 `<input list="...">` + `<datalist>`를 쓴다.

## 7. `<button>`

```html
<button type="button">버튼</button>   <!-- 아무 동작 안 함 (JS와 함께 사용) -->
<button type="submit">버튼2</button>  <!-- 폼 전송 -->
<button>버튼3</button>                <!-- type 생략 → 기본값 submit! -->
```

| | `<input type="submit" value="전송">` | `<button>전송</button>` |
|---|---|---|
| 버튼 글자 | `value` 속성 | 태그 사이 내용 |
| 내용 | 텍스트만 | 텍스트 + 아이콘 이미지 등 HTML 가능 |
| 닫는 태그 | 없음 | 있음 |

> ⚠️ **`<button>`의 기본 type은 `submit`** 이다. 폼 안에서 전송이 아닌 용도의 버튼(모달 열기 등)에 `type="button"`을 빠뜨리면, 누를 때마다 폼이 전송되고 페이지가 새로고침되는 버그가 생긴다.

## 8. `<textarea>` — 여러 줄 입력

```html
<textarea name="content" cols="50" rows="10"></textarea>
```

| 비교 | `<input type="text">` | `<textarea>` |
|---|---|---|
| 줄 수 | 한 줄 | **여러 줄** (엔터 가능) |
| 닫는 태그 | 없음 | 있음 |
| 크기 | `size` | `cols`(가로 글자 수), `rows`(세로 줄 수) |
| 크기 조절 | 불가 | 오른쪽 아래 모서리를 끌어 조절 가능 |
| 기본값 | `value` 속성 | 태그 사이 내용 |

> `<textarea>`와 `</textarea>` 사이의 공백·줄바꿈도 그대로 값이 된다. 비어 있게 하려면 붙여서 쓴다.

## 9. ➕ 브라우저 기본 유효성 검사

| 속성 | 설명 |
|---|---|
| `required` | 필수 입력 |
| `minlength` / `maxlength` | 글자 수 제한 |
| `min` / `max` / `step` | 숫자·날짜 범위 |
| `pattern` | 정규식 검사 (예: `pattern="[0-9]{3}-[0-9]{4}"`) |
| `readonly` | 읽기 전용 (값은 **전송됨**) |
| `disabled` | 비활성화 (값이 **전송 안 됨**) |
| `autofocus` | 페이지 열리면 자동 커서 |
| `autocomplete` | 자동완성 허용 여부 (`on` / `off`) |

> ⚠️ 이 검사는 **사용자 편의용**이다. 개발자 도구로 쉽게 지울 수 있으니 **서버에서도 반드시 다시 검증**해야 한다.

## 10. ➕ `<fieldset>`과 `<legend>` — 입력 그룹 묶기

```html
<form action="#" method="post">
    <fieldset>
        <legend>성별</legend>
        <label><input type="radio" name="gender" value="남성"> 남성</label>
        <label><input type="radio" name="gender" value="여성"> 여성</label>
    </fieldset>
    <button type="submit">제출</button>
</form>
```

관련 입력 항목이 테두리로 묶이고 `legend`가 그 제목으로 표시된다. 회원가입처럼 항목이 많은 폼에서 구조가 명확해진다.

## ✅ 마무리 요약

- `<form action method>` 안의 입력값이 `name=value` 쌍으로 서버에 전송된다
- **`name` 없으면 전송 안 됨**, 라디오는 **`name`을 같게** 해야 한 그룹
- GET은 URL에 노출(조회용), POST는 본문에 담김(등록·로그인용), 보안은 HTTPS
- `<label for>` + `<input id>` 연결로 클릭 영역 확대 + 접근성
- `<select>`는 보이는 글자가 아니라 `value`가 전송된다
- `<button>`의 기본값은 `submit`, 전송용이 아니면 `type="button"`
- 브라우저 검사는 편의용, 서버 검증은 필수
